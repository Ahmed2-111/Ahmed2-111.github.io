# Ahmed Al-Swaidi Portfolio Website

This is a personal portfolio website for GitHub Pages.

## How to use

1. Create a GitHub repository named:
   YOUR_USERNAME.github.io

2. Upload these files:
   - index.html
   - style.css

3. Go to:
   Settings → Pages → Deploy from branch → main → root

4. Your website will be available at:
   https://YOUR_USERNAME.github.io

## Important

Replace:
- YOUR_USERNAME
- your-email@example.com
- project links
